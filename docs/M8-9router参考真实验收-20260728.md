## 1. 参考语义

用户指定以下 9router 路径为本轮可信参考：

```text
9router
cx/gpt-5.5
cx/gpt-5.6-sol
```

本系统无法从黑盒 HTTP 响应独立证明 9router 是 OpenAI 官方直连。因此本轮将其记录为：

```text
referenceLevel = L2
provenance = 用户指定可信 serving path
surface = Codex（用户声明）
```

不能记录为系统识别的 L1 `api.openai.com`，也不能把结果称为官方认证。验证目标是第三方中转站相对该用户指定参考路径的短时行为相容性。

## 2. 预注册批次

场景：

1. 随想 `gpt-5.5` ↔ 9router `cx/gpt-5.5`
2. AiCodeWith `gpt-5.6-sol` ↔ 9router `cx/gpt-5.6-sol`
3. 随想 `gpt-5.6-sol` ↔ 9router `cx/gpt-5.6-sol`

执行：

```text
2 个时间窗口
每个场景/窗口 4 cells × 5 repetitions = 20 pairs
每个 run 40 endpoint observations
总上限 240 endpoint observations
实际 240
网络重试 0
单活跃 pair
raw response 不保存
结构化 observation 保存到脱敏 artifact
```

两个窗口间隔约 60 秒，只检查短时重复性。2026-07-28 用户取消 24 小时复测；后续改用同一会话内预注册、随机交错的多 block 稳健性验证。该替代方案不评估跨日漂移，报告必须明确“长期稳定性未评估”。

协议：

- 随想：OpenAI Chat Completions。
- 9router：OpenAI Chat Completions。
- AiCodeWith：OpenAI Responses。
- 产品面仍可能不同，且参考为用户声明 Codex surface；因此正式 comparability 保守记录为 P2，而不是 P1。

## 4. 可得结论

1. 三个第三方场景在本批 240 次请求中均可稳定访问，返回 model 字段与各自声明一致。
2. 相对用户指定的 9router reference，所有场景都形成了可计算的短时行为距离。
3. 随想 GPT-5.6-sol 在本次两个小样本窗口中距离较低；但第二窗口只有 3/4 cell 可比，且没有 calibration，不能升级为“行为支持”。
4. AiCodeWith GPT-5.6-sol 两窗口距离约 0.185–0.200；这可能来自 Responses/Chat、产品面、serving context 或真实行为偏移，当前不能区分。
5. 随想 GPT-5.5 两窗口从 0.112 漂移到 0.196；样本量不足以确认动态路由，但足以要求更长时间窗口复核。
6. 返回 `model` 一致仅为弱信号，不证明来源。
