## 恢复

需要恢复清理前数据时，必须：

1. 停止生产服务；
2. 备份当前新数据；
3. 恢复 `fresh-start-*` 中的完整数据目录；
4. 恢复对应安装和 systemd 配置；
5. 检查权限、SQLite integrity、供应商密钥和 Basic Auth；
6. 启动服务并执行 health/status/SPA smoke。

恢复会重新引入已删除的历史和参考，必须再次得到用户明确批准。
