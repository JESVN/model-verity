## 人工检查清单

1. 验证页直接显示“综合服务声明验证”，无版本、探索、Legacy 或暂停字样。
2. 验证方式显示“参考样本比对”和“实时双端配对”。
3. 产品面显示“API 接口/ChatGPT 产品/Codex 编程产品/企业专属部署/无法确认”，每项说明服务形态和选择条件。
4. P1/P2/P3 显示中文定义、适用条件、结论影响和当前推荐；厂商/产品/产品面不一致或 unknown 时阻止 P1/P2，协议不同时阻止 P1。
5. 临时第一方 Key 的内存使用和销毁说明清晰。
6. 预算按钮明确区分样本组和 endpoint 请求，说明实时配对为何请求数翻倍，并展示 token 上限和不自动扩大预算。
7. 运行页能取消，显示真实进度和成功/失败计数，不直接暴露内部 mode/phase 状态码。
8. 结果按行为、来源、稳定性、协议和时效五维展示，每维说明回答的问题和不能回答的问题。
9. JSD、可比覆盖、同源校准尾部概率、异源误接近风险和采样清单校验值均有中文解释，不显示模型真假百分比。
10. JSON、Markdown、CSV 和 7 天时点报告入口可用。
11. History 初始为空；新运行完成后可打开和删除；运行状态使用中文。
12. 参考样本页无暂停或 Enrollment 迁移说明；没有自建版本时仍显示“创建参考样本”。
13. 自建参考可选择可信供应商、模型、协议、L2/L3、身份和 20/80/240 次预算；每项说明选择方法；完成后进入验证下拉，失败/取消不发布版本。
14. 自建参考刷新和多标签可恢复；过期、复核或暂停使用后从可用验证列表移除，状态显示中文含义。
15. 供应商角色、协议、模型列表发现、密钥后端和连接错误类别均有中文说明。
16. 导航只保留验证、供应商、参考样本和历史；无无操作能力的设置页。
17. 数据与隐私说明显示在供应商密钥、临时 Key、验证和历史等对应操作附近。
18. 320–430px 无水平溢出；长解释不截断主要操作；主要操作触控高度至少 44px。
19. 键盘可遍历，焦点可见，Select 的副说明可读，确认对话框可退出。
20. reduced-motion 下无位移动画和脉冲。
21. 验证运行期间，“验证”导航按钮显示实时百分比；切到供应商、参考样本或历史后继续更新；点击该按钮返回当前运行。
22. 自建参考采集期间，“参考样本”导航按钮显示实时百分比；刷新和其他标签页恢复后继续更新。
23. 验证页顶部明确显示“验证结果仅供参考，无法保证百分之百准确”。
24. 默认验证首屏只包含供应商、模型、参考样本、检测深度、预算和启动按钮；协议和身份字段只在高级验证方式展开后出现。
25. 结果首屏显示 0–100 综合可信评分、等级、一句话结论和最多三条关键说明。
26. 五项评分组成显示分数和权重；P3、老化研究参考、低覆盖和行为混合的结论上限可见。
27. JSD、bootstrap、原始五维证据、manifest hash 和 limitations 默认折叠在技术详情。
28. History 不显示无 V3 scorecard 的旧运行；生产旧业务数据清理后为空。
29. 从 History 打开结果时侧栏保持“历史”高亮，独立显示“历史验证结果”；返回历史列表，“再次验证”才切换验证页。
30. History 结果“再次验证”会带入原验证方式、目标供应商/模型、参考、检测深度、协议和身份声明；不恢复 API Key 或旧预算授权。若原供应商、模型或参考不可用，明确提示重新选择，不静默改成其他配置。
31. 内置研究参考显示动态时效；2026-07-06 GPT-5.5 参考在 2026-07-30 应显示“仍可使用”，不是“已老化”。
32. 新内置参考运行的 manifest 为 `pamela-challenge@2` 且 `promptMode=fixed`；实时双端和自建参考为 `promptMode=marked`。
33. 对 JSD 低、请求质量/覆盖完整、短时稳定但仅受 P3 研究参考限制的结果，首屏主数字显示“行为相似评分”，并显示“行为高度/较为相似”、独立“来源证据待复核”和次级综合证据分；低覆盖、低成功率、行为混合或较大 JSD 仍显示“需要复核”，技术详情可见两项分数、原始等级和 cap 后等级。
34. 主评分环颜色与展示指标一致：85–100 绿色、70–84 柔和绿、50–69 黄色、0–49 红色、无分灰色。98 分行为相似评分必须为绿色，同时“来源证据待复核”badge 保持黄色；真实质量/稳定性 cap 的结果仍按 cap 后等级显示黄色或红色。
35. 历史记录的时间、验证方式、状态和评分摘要在桌面与 320–430px 窄屏均清晰可读；正文/说明至少 13px、行高至少 1.55，短 badge 和技术元数据之外不出现 11px 以下文字。
36. 供应商、验证、参考样本、History 和结果技术详情中的非日常名词均先用普通语言解释“是什么、怎么选或怎么判断、影响什么”；P1/P2/P3、L1/L2/L3、JSD、校准、token 和采样清单校验值不得只显示缩写。
37. 展开 Select、高级验证方式和技术详情后，长解释不遮挡操作、不造成水平溢出；键盘焦点、屏幕阅读顺序和移动端滚动仍可用。
38. 页面说明、字段帮助和 Select 副说明不重复堆叠同一信息；默认帮助保持一句话，普通流程可快速扫读，专业边界仍能在就地说明或技术详情中找到。
39. 主要深色表面上的次要文字对比度至少 7:1，弱辅助文字至少 5.5:1，绿色、黄色、红色状态文字和品牌文字至少 4.5:1；层级仍可通过字号、字重和间距区分。
40. 暖橙主按钮默认和 hover 使用深色文字，按下态使用深橙底白字；桌面、移动端、键盘焦点和 disabled 状态均清晰可辨。
41. 新浏览器首次打开验证页时，有可用数据即默认选择第一个验证供应商、该供应商第一个模型和第一个参考样本；无供应商、无模型或无参考时保持空值并显示正确提示。
42. 修改供应商、模型、参考样本、检测深度、验证方式和高级身份配置后刷新，选择保持不变；删除已保存资源后回退到当前第一个可用项。临时 API Key、预算授权和 credential session 不出现在浏览器偏好中。
43. History“再次验证”遇到已删除的供应商、模型或参考时仍明确要求重新选择，不受浏览器偏好影响，也不静默回退。
44. 首次根数据加载、参考治理数据加载和上次运行恢复显示统一暖橙四格加载状态；屏幕阅读器可获得状态文案，`prefers-reduced-motion` 下四格保持静态且没有循环动画。
45. 供应商页“编辑”点击后弹出独立对话框修改该供应商，不再在“添加供应商”表单中改写；编辑弹窗桌面、移动端和键盘均可用，保存后关闭并刷新列表，取消不产生变更。
46. 创建参考样本表单可从所选供应商的模型列表接口获取模型 ID 并选择填入；“产品形态”字段名和说明清楚解释它指模型以哪种方式被提供和使用，选项包含选择依据与影响。
47. 供应商配置包含长地址、长模型 ID 或多个模型时，“测试连接”“编辑”和删除操作仍保持一致布局；桌面按钮文字不换行，320–430px 窄屏不横向溢出。
