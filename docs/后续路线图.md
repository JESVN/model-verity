# 后续路线图

> 当前生产已完成综合服务声明验证框架切换和业务数据重置。路线图从现行产品出发，不再按旧版/新版 UI 并行规划。

## 当前生产基线

- 行为、来源、稳定性、协议和时效五维结果；
- 参考样本比对和实时双端配对；
- OpenAI Chat Completions、OpenAI Responses、Anthropic Messages；
- L1/L2/L3 参考等级和 P1/P2/P3 协议可比性；
- Pair 内并发启动、实际 start gap 和结构化 observations；
- 原子请求/token 预算；
- 临时第一方凭据；
- JSON/Markdown/CSV 和 7 天时点分享报告；
- History 恢复、删除级联和多标签跟踪；
- SSRF、redirect、dangerous headers、脱敏和密钥生命周期门禁；
- 33 个主流厂商 PAMELA/OpenRouter 研究参考（claude、openai、gemini、deepseek、kimi、qwen、glm、grok）；内置比较使用固定 prompt，实时配对/自建参考使用 marked prompt；
- `pamela-challenge@2` manifest 显式保存 `promptMode`；
- 内置参考按 0–14/15–45/>45 天规则计算 current/usable/stale。

生产数据从空业务状态开始，只保留用户已添加的 3 个供应商及其加密密钥。

## 近期：统计覆盖提升

- 为允许的 Vendor/Product/Surface/Protocol/Profile 组合建立独立 calibration；
- 扩充 genuine 和 impostor 案例；
- 分开开发集和冻结 holdout；
- 报告强结论覆盖率、需要复核率和不可验证率；
- 只有数据证明后才启用预注册的 1%/1% 强结论；
- GPT-5.5 与 GPT-5.4 当前不可分场景继续保持未校准或需要复核；
- 为同一参考分布不同样本量下的 plug-in JSD 建立有限样本偏差校准，不能把原始 `100×(1−JSD)` 当真实性概率；
- 评估 Core/Discriminative cell 分层，减少高熵开放 cell 对低预算均值的偶然支配，但必须预注册并用 holdout 验证，不能按单次结果删 cell。

## 中期：参考治理

- 增加完整的 cohort 创建、导入和归档 UI；
- 为 L1 官方 endpoint 增加 origin allowlist 和厂商 policy；
- 已实现默认 0–14/15–45/>45 天 freshness；后续增加厂商级 policy，并继续区分 rolling alias 与 exact snapshot；
- 增加 reference heartbeat，但默认不自动产生付费请求；
- 支持经过协议、许可和 hash 校验的外部参考包导入。

## 中期：Runner

- 序贯 block 自动停止，只允许减少费用；
- Replacement pair 和首次/最终成功率报告；
- Endpoint 独立 429 backoff；
- Time-gap calibration；
- 更完整的 block mixture、conditional fallback 和 change-point 分析；
- 用户明确授权的实时阴性对照。

## 中期：产品和报告

- 分享页提供过期、撤销和配置变更可视化；
- 报告签名或可验证 receipt；
- History 搜索、筛选和批量删除；
- Reference version 详情和治理事件时间线；
- 更明确的费用估算，不使用自动追加预算。

## npm 发布

当前 npm 仍为 `0.1.0`。新版本需要：

1. Review #006 人工批准；
2. `npm pack` 内容检查；
3. 临时目录独立安装；
4. CLI/API/SPA smoke；
5. 用户单独批准发布；
6. 发布后撤销短期 token。

## 明确不做

- 云端 SaaS 代存用户 API Key；
- 把行为距离写成模型真假概率；
- 宣称厂商认证或密码学来源证明；
- 默认监听公网；
- 未授权的付费阴性采样；
- 为使结果好看而补样或移动阈值；
- 自动越狱或攻击型 probe。
