## 1. 结论策略

- 服务端统一执行证据策略，有限样本不得输出未经校准的确定性身份结论。
- `supported/anomalous` 在不满足发布门禁时降级为行为相容迹象或行为偏移。
- `strongConclusion` 保持 `false`。
- 结果说明不提供固定错误率保证，长期稳定性未评估。
- 当前 UI 不展示内部 policy、framework 或 schema 版本名称。

## 2. 预算授权

- 预算绑定供应商、模型、最大请求、最大 input/output tokens、最大 attempt 和有效期。
- SQLite transaction 原子预留 endpoint 请求。
- Provider 返回 usage 后累计 token，超过停止线后终止后续请求。
- Run budget 不能超过 authorization。
- Token 超限不会伪装为供应商错误。

## 3. Pair runner 与协议

- 调度单位为 pair。
- Pair 内两端近同时启动，启动顺序由 manifest seed 确定性随机。
- 保存真实 `startGapMs` 和 p95。
- Target/reference adapter protocol 分别固化。
- 不同协议不能声明 P1。
- Chat/Responses crossover 只作协议诊断，不使用固定数值修正其他距离。

## 4. 临时凭据

- 临时第一方凭据只保存在内存。
- 凭据绑定 run ID 和 endpoint role。
- 默认 15 分钟，最长 60 分钟。
- 完成、失败、取消、过期和 shutdown 后删除。
- 不写 SQLite、History、日志或导出。

## 5. History、恢复和删除

- History 只展示当前框架新产生的验证记录。
- 刷新和多标签页可恢复当前任务。
- 服务重启将未完成任务标为失败，不自动重发真实请求。
- 删除运行会级联删除 manifest、observations、attempts、evidence、conclusions 和分享报告。

## 6. Reference governance

- Reference cohort、immutable version 和 append-only governance event 已落地。
- L1/L2/L3、freshness 和 quality 分离。
- 参考内容不会被治理状态更新覆盖。
- L2 用户指定路径不能升级为 L1。

## 7. 报告

支持：

```text
JSON
Markdown
CSV
7 天时点分享报告
```

报告包含 endpoint hash、provider config revision、隔离后的 credential-scope HMAC、证据范围和过期/撤销状态。报告不包含 Key、query、fragment、userinfo 或原始认证 header。CSV 包含公式注入防护。

## 8. 安全

- Base URL 禁止 userinfo、query 和 fragment。
- 请求禁止重定向。
- DNS 解析后检查 loopback、私网、link-local、CGNAT 和保留地址。
- 默认生产拒绝私网 provider endpoint。
- Header 禁止 Authorization、Proxy-Authorization、Cookie、Host、Connection、Content-Length 和 Transfer-Encoding。
- 本地 mock 仅在显式设置 `MODEL_VERITY_ALLOW_PRIVATE_ENDPOINTS=1` 时允许私网地址。
