# Preview Lab 界面验收与审批记录

## 门禁规则

1. 仅修改 `src/web/src/ui/**`、`src/web/src/preview/**`、fixtures 与本文件时，可进入预览评审。  
2. 运行 `npm run preview:ui`，逐场景验收。  
3. 评审人填写下方 **Review 记录**。  
4. 状态为 **Approved** 后，才允许 `app/` 与 server 接线对应界面。  
5. 任何改动已批准布局的 PR/提交，需新开 Review 编号。  

---

## 通用检查清单（每次复用）

### 信息架构

- [x] 首屏只回答「相对参考的可信度」  
- [x] Setup 字段克制（无默认 raw/公式/探针全文）  
- [x] Result：先结论，后依据（依据默认折叠）  
- [x] 无 reference 时不能出现绿/黄/红「匹配」结论  

### 可信度表达

- [x] 三档 + failed 语义正确  
- [x] 颜色 + 文字双编码  
- [x] 禁用「真/假模型」「官方认证」等绝对措辞  

### 进度与动效

- [x] 验证中进度映射真实完成比（Preview 明确标为 mock）  
- [x] 取消操作可见；业务接线后必须保持可打断  
- [x] 默认无过度弹跳；reduced-motion 可降级  

### 安全与隐私

- [x] 无 API Key 明文  
- [x] Preview 顶栏标明 mock / not live  

### 适配

- [x] 桌面双栏可用  
- [x] 窄屏单列不坏档  
- [x] 固定深色主题可读  

### Apple 风格克制

- [x] 留白与层级清楚，无仪表盘堆砌  
- [x] 主按钮/主结论一眼可见  
- [x] 系统字体与语义色一致
