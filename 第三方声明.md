# 第三方数据与软件声明

`model-verity` 包含从公开研究数据生成的内置行为指纹，以及为兼容该数据协议而移植的软件逻辑。

## PAMELA / Bruckner 研究数据

- 作者：Tomáš Bruckner（ORCID `0000-0001-9120-556X`）
- 数据集：*Single-token output distributions as behavioral fingerprints of large language models*
- DOI：`10.5281/zenodo.21278557`
- 许可：Creative Commons Attribution 4.0 International（CC BY 4.0）
- 原始采集：`main-02`，通过 OpenRouter 聚合路由采样，不是模型厂商第一方证明；名义每 cell 30 次，高价模型可能按原研究配置减半，实际样本量以每 cell counts/`nValid` 为准
- 项目变更：`scripts/build-builtin-library.mjs` 从 `normalized.jsonl` 重新聚合整数计数，筛选 40 个 paper-1 cells 均存在且每 cell `nValid >= 10` 的模型，保存 counts、probs、有效性计数与来源元数据，并 gzip 压缩为运行时只读资源
- 内置结果：原始库 146 个模型；30 个候选因覆盖或有效样本不足被排除。2026-08-05 起运行时内置库缩减为 33 个主流厂商模型（claude、openai、gemini、deepseek、kimi、qwen、glm、grok），其余模型数据仍保留在原始 Zenodo 数据集

CC BY 4.0 全文：<https://creativecommons.org/licenses/by/4.0/legalcode>
